# Governor Zue Worldwide

A premium, mobile-first music portfolio for Nigerian recording artist **Governor Zue**. Built with a high-end dark aesthetic: pure black, bold white typography and metallic gold accents.

## Features

- Full-bleed looping video hero with a photo fallback
- Floating audio player with a spinning vinyl graphic
- Latest video showcase in a vertical player
- Complete discography grid
- Biography section
- Swipeable photo gallery with a full-screen lightbox
- Booking and fan registry forms with validation
- Slide-out mobile navigation drawer with active-section highlighting
- Scroll-triggered animations using the Intersection Observer API
- Streaming links for Audiomack, Boomplay, Apple Music and Spotify

## Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, custom properties)
- Vanilla JavaScript (no frameworks)

## Run Locally

1. Clone the repository
2. Open the folder in VS Code
3. Right-click `index.html` and choose **Open with Live Server**
